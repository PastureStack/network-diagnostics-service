# Origin and distribution boundary

The historical feature reference is [`rancher/network-diagnostics`](https://github.com/rancher/network-diagnostics). GitHub keeps this repository in that fork network so the origin remains visible.

The historical upstream repository does not contain a repository-level license, and GitHub reports no detected license for it. PastureStack therefore does not copy the upstream source tree, vendor directory, executable artifacts, or reachable Git history into the public `main` branch, source archive, release, or container image.

The current root commit is a new PastureStack implementation written with the Go standard library. It provides a bounded authenticated snapshot API, aggregate status, retention, and ZIP bundle lifecycle. It does not claim ownership of, license, or compatibility rights over historical upstream expression.
